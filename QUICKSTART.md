# 🚀 Quick Start Guide - FREE VERSION!

## ✨ No API Key Required! Just Run It!

Your live tracking system uses **Leaflet** - a completely FREE and open-source mapping library. No Google Maps API key needed!

### 🎯 Get Started in 1 Step!

1. Make sure dev server is running: `npm run dev`
2. Open browser: **http://localhost:3000/live-tracking**
3. Click the **Play** button
4. Watch 50,000+ animals move in real-time! 🎉

That's it! No configuration needed!

---

## 🎮 How to Use

### Controls

- **Play/Pause**: Start/stop animation
- **Reset**: Go back to beginning
- **Animal Filters**: Click to show/hide species
- **Select All/Clear**: Quick filter controls

### Map Interaction

- **Click markers**: View detailed animal info
- **Zoom**: Mouse wheel or +/- buttons
- **Pan**: Click and drag
- **Satellite view**: Automatically enabled

### What You'll See

- 🔴 Red markers = Running/Chasing
- 🟢 Green markers = Resting
- 🟡 Yellow markers = Eating/Drinking
- 🔵 Blue markers = Near water

## ❓ Troubleshooting

**Map not loading?**

- Refresh the page
- Check browser console for errors
- Make sure dev server is running

**No animals showing?**

- Click "Select All" in the filter panel
- Click "Play" to start animation
- Check that CSV file exists in `/public/`

**Markers not appearing?**

- Wait a few seconds for data to load
- Click "Play" to start the animation
- Try refreshing the page
